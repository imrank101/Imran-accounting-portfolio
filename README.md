# Muhammad Imran — International Freelance Accounting Portfolio

Responsive static website built with HTML, CSS and vanilla JavaScript. Includes six fictional sample reports in Excel and PDF.

## Before publishing
1. Edit `script.js`: replace `YOUR_EMAIL@example.com` with your real professional email.
2. Replace `https://www.linkedin.com/in/YOUR-PROFILE/` with your actual LinkedIn profile URL.
3. Update employer names and dates in `index.html`, or remove the placeholder notes.
4. Check that every listed service and software tool reflects your real capabilities.
5. Keep the fictional-data disclaimers visible.

## Run locally
Extract the ZIP and open `index.html` in a browser. Alternatively, run `python3 -m http.server 8000` in the project folder and visit `http://localhost:8000`.

## Free GitHub Pages deployment
1. Create a public GitHub repository (e.g. `imran-accounting-portfolio`).
2. Upload `index.html`, `style.css`, `script.js`, `README.md` and the entire `sample_reports` folder to the repository root.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**, branch `main`, folder `/ (root)`, and save.
5. Wait for GitHub Pages to publish; the URL appears on the Pages settings page.
6. Open the live site on desktop and mobile. Test all report links and the contact form.

## Contact form limitations
GitHub Pages is static hosting and does not process form submissions by itself. This form validates fields and opens the visitor's email app with a pre-filled draft. The visitor must press Send in that email app; some visitors may not have one configured. For a true browser-submitted form, connect an external form service or backend and test delivery before claiming it works. Never put private API keys in browser JavaScript.

## Sample reports
All names, transactions, quantities, dates and amounts are fictional. Excel files are editable templates with basic formulas where applicable. PDF files are previews. They are not actual client reports or proof of completed freelance engagements.
